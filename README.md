# QR+ (ExtendedQR)

**Hybrid Standard + Extended QR Code Generator and Scanner**

QR+ (ExtendedQR) is a Python-based tool that allows you to create **hybrid QR codes** combining:

1. A **standard QR stub** — readable by any normal QR scanner, containing:
   - Sequence info for the extended reader
   - Link to instructions (GitHub repo)
2. An **extended QR payload** — for larger data storage, readable by our custom extended QR reader

This project includes both a **creator** and a **scanner**, enabling you to encode and decode QR+ codes efficiently.

---

## Features

- Extended QR payload encoding
- Metadata headers for size and target bytes
- GUI for easy file input and configuration
- Fully digital-optimized, no error correction required
- Cross-platform prototype in Python
